# Stage98 研究复盘：从几何模型扩展转向能量歧义、概率目标与可见活动

日期：2026-11-04。回应用户对最新进展、卡点和创新方向的再次复盘请求。读取 stage94–97、相关历史 workbook、训练源码和已保存学习曲线，检索原论文。**本阶段不训练、不做模型或事件推断、不读取事件 ROOT/NPZ、不恢复 CERN 环境、不提交作业、不做 SHA 校验。** 下列实验数值均来自已有记录；新增方案的收益、显著性、成本、系统效应和功效均为**未测量**。

## 1. 核心结论与本次修订

1. **有进展，但主要是排除了若干假设，尚未得到满足完整项目目标的新重建器。** stage94 已实际完成上次建议的五格九 fit，不能再建议“先跑五格”作为新工作。补齐输入和模型方案有条件增量；stage96/97 的候选几何与联合消息则没有确证总体收益。
2. **训练的全局最佳仍未证明，但继续扩大当前几何网络的研究优先级已经降低。** 最低能传统、stage92 后验、stage94 E 集成、stage97 B 的 log-RMSE 分别为 0.145661、0.165630、0.276027、0.297487。与此同时，stage94 E 的总体与困难侧远好于 stage92。反复出现的是不同方法沿同一个风险权衡移动，而非某个架构同时改善全部层。
3. **下一个科学问题应变成：在相同低重建 pz 下，现有或新增读出能否以足够小的低能误判代价，识别真正高能/大 transfer 的事例？** 不再只看总体 BCE、AUC 或新变量是否存在，而是看它是否在物理所需的工作点有效。
4. **保留原生关联研究，但不把“提到协方差/cluster ID”当作必然解除歧义。** 优先提取相对缪子轨迹的未归属活动、横向/纵向分布和读出支持；缪子误差摘要是有用的质量输入，但目前证据不支持它是最低能失败的主要解释。
5. **另开一个成本低且独立的概率分支。** 已保存学习曲线显示，stage94 的点 MSE checkpoint 与概率 NLL checkpoint 不一致；可先做保持点均值不变的概率尺度校准，而不等待 native 输入。这只能改善概率产品，不能冒充低能点重建恢复。

原 stage97 计划的 stage98 native-only 测量**尚未执行**。本报告占用 stage98；下一实际实验改为 stage99。路线由“唯一 native 前置”改为两个可独立交付的工作包：**A：已有输出的决策诊断与概率产品；B：原生关联和可见活动的物理测量**。后续能量训练由明确的信息证据触发，不自动再开架构/seed 网格。

### 2.3 候选与协方差分支的价值和限制

[stage95](2026-11-04_stage95_track-candidate-information.md)固定 2048 个不同 train/cal incoming，1923 个 PHYS 可读。多轨迹 153/1923，leading 未确认 132 个，其中只有 4 个有备选确认 primary。最低真能量的 **81 个可读事例全是单轨迹**；允许保留 leading 或换成已确认候选的 μ-pz oracle 为 **0.483590902→0.483329547**，仅 2 例改善。此 oracle 不是 ν 能量上限，也不覆盖未保存的轨迹/击中。

这削弱了“仅换对已保存的缪子候选就能修复最低能”的假设。原 PHYS 已要求候选跨三站，低能淋浴的短轨迹/局部击中可能没有变成保存候选；单轨迹不等于只有一个末态粒子，更不等于没有可测强子活动。

真正的已知缺口是：hitSet 只是 24-bit 层/面覆盖，且 52/1923 事件与保存轨迹长度不齐；共同面外推的单位协方差不是拟合误差。stage96/97 没有真实 track→cluster/SP 引用或实测 covariance。引入这些观测有物理理由，但它们的能量增量仍未测量。

stage73 在旧划分低能确认者中已测得 μ 响应项均方 **0.002373**、附加修正项均方 **0.106907**、交叉项 **−0.016830**，总均方 **0.092449**，均为无量纲平方 log 量。它支持“ν 修正比 μ 核心误差更值得优先研究”，但 signed 交叉项使它不是唯一因果分账；旧人数与新 split 不混用。新 covariance 可能帮助困难尾，不能预先说它能补回全部 transfer 信息。

## 3. 卡点应怎样重新表述

### 3.1 相同低 pz 中竞争的是两种能量解释

在前向近似下 pμ≈(1−y)Eν。选中 pz0>50 的真低能事件偏向小 y；同样 pz0 的真高能事件可能有大 transfer，或者 leading 不是可确认的 primary。stage86 旧样本中的低 transfer 与高 transfer 分布已支持这种混合，不需要重新猜测。

令 t=ln(Eν/GeV)、m=ln[(pz0/0.8)/GeV]、c(X)=新模型相对传统的 log 修正，e0=m−t。对任意固定评价组 g，平方 log 风险满足精确恒等式：

\[
R_g(m+c)-R_g(m)=\mathbb E_g[c^2+2e_0c].
\]

在传统已经接近正确的低能组，较大的正修正容易付出 c² 代价；在真实高能但 pz 低的组，正修正可能必需。**需要学习的是哪些观测能可靠决定修正，而不是一律增加或减小修正。** 这不是证明物理不可辨识：我们尚未测到全观测的 Bayes 风险。

### 3.2 已经否定了哪些过于简单的解释

- 不是只缺一个训练 seed：stage94 的固定三 seed 集成未恢复最低能；当然也没有覆盖全部训练方差。
- 不是只要把节点与边接起来：stage97 已测正确配对消息，未建立增量。
- 不是所有低能尾都来自坏重建：stage73/86 普通有效低 transfer 事例也有尾。
- 不是只要能量均匀重权：stage73 早已实测低能改善伴随困难组损害。
- 不是把模型换成 posterior 就消除先验：stage62/74/76、stage87–92 已研究过连续密度、条件判别和物理后验，不把这些重新包装成新方法。
- 不是只需一个 global offset：stage94、96、97 都重复看到总体改善而最低能变差。

## 4. 新发现：点模型选择与概率模型选择尚未分开

这部分直接读取 stage94 的三个已保存曲线（[494](stage94_energy_ml/learning_E_2026110494.tsv)、[495](stage94_energy_ml/learning_E_2026110495.tsv)、[496](stage94_energy_ml/learning_E_2026110496.tsv)），没有新推断。E 用 marginal NLL 训练，但[训练源码](../ml/compare_energy_architectures.py)按 cal_select **点 MSE** 选择唯一 checkpoint。三个 seed 的最小验证 NLL 轮次均更早：

|seed 尾数|已选点 MSE epoch|该 epoch 验证 NLL|已记录最小 NLL epoch|最小验证 NLL|
|---|---:|---:|---:|---:|
|494|65|−0.135048985|50|−0.143989831|
|495|90|−0.120730676|25|−0.137924746|
|496|65|−0.134592965|35|−0.143561393|

这些值是同一验证支持上的每 incoming NLL，无量纲，不是新的 test 比较；早期权重没有全部保存，不能事后声称早期模型的 test 更好。它们说明：**继续加 epochs 不是当前证据支持的默认解法；概率 NLL 已出现泛化退化，而点 MSE 仍可能下降。**

stage94 E 集成的 test 68/90% coverage 为 **62.602337%/86.253883%**，相应条件区间 **[61.681838,63.398361]%/[85.662856,86.912447]%**。PIT 两端增多；raw/offset NLL 为 **−0.114574734/−0.107503598**，点校准并未优化该 NLL。这里总体和 X 分组本身有问题，不依赖错误的“真 E 组 PIT 应均匀”要求。

### 4.1 立即可做的概率改进：保持点均值的尺度校准

对保存的 MDN logE 随机变量 Z，记其预测均值为 m(X)，旧点 offset 为 b。只增加一个 T>0，定义：

\[
Z'=m(X)+b+T[Z-m(X)].
\]

混合分量变为 μk′=m+b+T(μk−m)、σk′=Tσk，权重不变；**均值恰好保持 m+b，点能量与旧输出完全一致**。在原 cal_post 上只拟合一个 T 的 NLL，再评价完整开发 test 的总体/X 组 PIT、coverage、宽度和 NLL。这是新的概率后处理，不是新的能量网络；cal_post 已用于 b，独立性与参数估计限制如实写明。

如果它改善区间而点风险不变，得到一个有用但有限的概率产品；若局部组仍相反，则支持形状/条件失配，不继续堆温度网格。Cal-PIT 可作为下一步局部诊断，但小 cal 不能支撑任意复杂修正。[LADaR / Cal-PIT](https://arxiv.org/abs/2205.14568)

### 4.2 一次有条件的训练修正，不再泛扫架构

如果概率产品确有用途，之后最多做一次原 seed、原输入/MDN 的重训，同时保存预注册的 **NLL-best 与 point-MSE-best 两个 checkpoint**，分别评价概率与点目标；一个训练轨迹不算两个独立模型确认。不能用当前 test 选轮次，也不假定 NLL-best 会改善最低能。把当前点 checkpoint 的欠覆盖等同于整个概率方法家族无效，同样证据不足。

## 5. 主要新研究：把信息增量测在真正需要的工作点

### 5.1 做一个任务匹配的歧义测量

在固定 50<pz0<100 的观测人群中，定义诊断标签 L=真 E 50–100、H=真 E≥200；100–200 仍完整参与能量风险，只是在这项二类诊断中单列。标签仅训练/评估使用，不作部署输入。

先用已有输出给四种**固定分数**：pz-only、direct 点输出、stage94 E 的高能概率相对低能概率、stage92 已保存准确 CDF 的相应质量比。概率分数可写作 P(E≥200|X)/[P(50≤E<100|X)+P(E≥200|X)]，分母为 0 时保留未定义状态而不按真值修补。MDN 用解析 CDF；stage92 只在已有保存边界质量确实可用时复用，不为这项诊断重开全量积分。

评价应包括：

- 相同 pz 支持内的 ROC/低误判率部分，而不只报告全域 AUC；pz 分布差异用 train/cal 事前共同格标准化，空格保持缺口。
- 在低能误判率名义工作点 2%/5%/10% 时，高能识别率、支持、区间及实际能量风险。工作点只是诊断网格，**不等于原 tail≤+2pp 或 RMSE 门槛**，也不据 test 选择部署阈值。
- 实际 c 的均方和 e0c 交叉项、低能过修正与高能欠修正的损失贡献。二类 ROC 不能替代连续能量重建结论。

这与 stage74 的平均 BCE 判别增量、stage78 的有限专家凸组合不同：本次回答“已有分数在严控低能误判的区域是否有用”，不是再训练同一种能量 classifier/gate。分数若有良好排序却难校准，优先修决策/概率；若只能在高误判率下分离，优先购买新的可见信息。负结果仅限制这些分数，不认证 Bayes 下界。

### 5.2 统计功效本身是一项真实限制

Neyman–Pearson 分类强调优先控制某一类错误，而不是靠平均分类准确率代替。分数阈值的经典非参数控制也需要足够的独立校准支持。[Tong、Feng、Li，Science Advances 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5804623/)

作为数学示例，在 iid、适当独立阈值校准的条件下，零误判的 95% 单侧上界为 1−0.05^(1/n)；要达到 2% 或 1%，最少分别需要 **149 或 299** 个独立低能校准事例。当前 cal_select/post 的最低能记录为 85/97，且存在来源相关和既往选择，**不能给当前分数套用这种总体保证**。这些数字是公式的样本量示例，不是本项目功效测量。

不应把宽区间当作没有信息，也不应靠 bootstrap 复制出 299 个独立低能事例。当前可以做开发诊断，正式错误率保证仍需合适支持；这不是停止当前研究的理由。

## 6. 最值得新增的物理输入：相对 μ 的活动，而非更多轨迹几何

### 6.1 改写 native 提取的科学目标

原 native 计划有价值，但交付对象应从“有关联 ID 和 covariance”进一步明确为：**能否观测到超出选中缪子贡献的带电/淋浴活动，以及它是否与 H/L 歧义相关？**

继续复用 stage95 固定 2048 train/cal incoming、一视图/24 source，不按真 E、y 或误差挑样本；沿精确生产链寻找已有 REC/ESD，缺源身份和 K 支持全部保留。若实际引用可核，冻结一族紧凑摘要：

1. 每 station/面被任一有效轨迹关联的唯一 cluster/SP，与其余活动的计数及有效 collection 分母；SP 与组成 cluster 分开，不重复计能量。
2. 其余活动相对 leading 轨迹的横向分布、station 间增长/起始结构；不预先把“未归属”标成噪声或强子。
3. 与 active plane/模块边界的几何支持、外推失败和可核轨迹误差尺度。协方差用于质量/几何解释，不直接换算成 ν 能量。

真实共享 ID 与物理重复轨迹不等价，不能据共享率删事件；单轨迹事件仍要提取未归属活动，不能把新分支只作用在少数多轨迹者。没有可靠 ID 时不使用 hitSet 交集或长度强配代替；可先做 collection 级分布并明确哪些量未测。

### 6.2 更物理的表示：相对单 μ 控制的残差或条件秩

对确实有共同定义和支持的读出 Vj，利用独立 μ 控制估计条件响应 Fμ,j(Vj|pz、位置、方向、状态)，构造条件秩，或保留 signed 残差 Vj−Eμ[Vj|条件] 和响应尺度。它可以减少路径长度、位置和 μ 本身活动对 shower proxy 的混淆；不要求 raw/残差非负，也不把多个通道秩当作相互独立。

**若只是现有 62 输入的确定变换，它不增加观测信息**，可能的价值来自控制样本约束和归纳偏好；实际 cluster 关联/未归属结构才是新增信息。控制失配或支持外外推可能反而制造错误，不能预先称为标定。

stage52/85 的主要 μ 控制为 100–1000 GeV，且存在 tag、trigger、geometry 和 collection 条件；不能把其响应无条件外推到本项目 50–100 GeV，也不能用四 Veto 的电荷 tag 再证明这四通道低信号效率。native 测量先行；若没有低动量共同控制，低区残差校准明确列为缺口，不能据“μ 都是 MIP”假定已知。

### 6.3 训练之前先验证新增输入的用途

在可交付的固定 train/cal native 队列上，用同一个低容量、预注册分类器，做恰两格：现有 62 摘要 vs 62＋一族关联活动。保持来源/incoming 角色，超参数固定、同 seed，不按 cal 结果补特征或换网络；缺源/空集合状态分开，队列仍完整保留。

先报告同 pz 的条件 log-score/Brier、低误判率识别率和完整支持。样本不足的工作点写未测/不可认证，而不是零风险。小队列的正结果只触发后续完整输入提取和能量消融；负结果也需区分“引用不可用”“分辨率/几何不够”“该统计量没有增量”，不能直接称为物理不可辨识。

只有新族给出有支持的跨来源开发增量，下一轮才在完整角色做两格能量模型；优先在目前强的 BDT 上加少数物理摘要，避免小弱 MLP 的基线损失掩盖新信息。若后续用图模型，依据应是实际测量关联，而不是仅凭网络名称。[HGPflow，EPJC 2025](https://arxiv.org/abs/2410.23236)

## 7. 仍值得保留的创新分支与边界

|方向|潜在用途|当前建议|
|---|---|---|
|能量优先的联合密度 p(logE,f\|X)=p(logE\|X)p(f\|logE,X)|将物理标签监督与最终能量目标分开，检验 latent 约束是否损伤总体|保留候选；stage69 辅助分类已有负结果，不能只把辅助标签换名就称新信息。先完成决策诊断。|

|真正同一 interaction/末态的多重响应视图一致性学习|降低模型对数字化/重建扰动的依赖|仅相同 incoming 四动量不够：可能是不同 GENIE 相互作用；未核完整谱系前不得造 contrastive 正对。|

IceCube 在相近能区分别重建 track 与 cascade，说明分开处理两类响应有物理依据；其探测器与包含条件不同，不能迁移其分辨率。[DeepCore inelasticity，PRD 2025](https://arxiv.org/html/2502.13299v2) Kopp 等支持从可见末态推断不可见能量，但 DUNE 结果不是本探测器的预期收益。[中微子能量 ML，2025 修订](https://arxiv.org/abs/2405.15867)

更长期必须控制 interaction/FSI、可见/不可见能量分配和探测器响应。2026 年 FSI 研究进一步说明不同探测器的能量估计受不同可见性机制影响；它不证明本项目有相同偏差，也不支持现在直接做 data/MC 能谱重权。[Dolan、McKean、Munteanu，2026](https://arxiv.org/abs/2605.28696) prior/损失与频率学响应的区分见 [Gambhir 等的校准研究](https://arxiv.org/abs/2205.05084) 和 [Learning Uncertainties the Frequentist Way](https://arxiv.org/abs/2205.03413)。
