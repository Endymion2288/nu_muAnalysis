# stage40 后的研究修订：先测可见信息，再决定修复与模型投入

日期：2026-11-01。本轮复核 stage30–40，承接 stage29 的研究复盘。本文是研究方案；不包含新的训练、ROOT 读取或数值重算，所有新方向的收益均为**未测量**。

**判断：已有独立的重建进展，也定位了真实程序问题；但 stage36–40 的成功指标主要是电荷响应，尚未回答这些改进能否帮助 ν 能量。下一步应先开展有预算的信息诊断，而不把完整历史 Athena 生产复现设为所有物理研究的前提。**

## 2. 卡点的核心：三个问题被串成了过长的前置链

需要分开回答：

1. **物理采样**：这些探测器位置实际采到了多少能量分配信息？如果 ν 在 CaloNu 下游相互作用，CaloNu 通常不能作为完整的前向强子量热器；可能主要看到背散射、少量活动或没有沉积。具体机制仍需按实际敏感体与输运验证。
2. **电子学可见度**：已有敏感层信号经过噪声、时序、阈值和基线估计后，还剩多少可用信息？stage40 表明大幅改善长窗积分仍可能只是在噪声主导区域改善电荷估计。
3. **推断利用**：读出中的信息能否被现有回归器利用，且不依赖模拟专有标记？这是能量与谱的任务，不能只用电荷 RMSE 验收。

此前把完整 Athena 响应闭合设为后续能量研究的必经门槛，依赖过强。生产修复对真实部署是必要工作；但已有 HITS 可支持理想读出诊断，现有 PHYS 可支持零标记消融。这两项不必等待完整生产复现。

重点应继续是 **reco pμ=100–1000 GeV**，保留 100–250、250–1000 子层。它不是 Eν=100–1000 GeV：低 pμ、高 y 的目标事件仍可有很高 Eν，不能误删这些事件。高 μ 动量仅作参考，不要求把 TeV 谱仪响应修成低动量精度。

## 3. 下一轮首选：信息诊断，而非继续增加读出验收层

### 3.1 最便宜的第一项：旧零标记究竟贡献多少

用 stage35 **开发分区**，保持 F6、事件、划分、容量和校准一致，比较：

- X=F6；
- X 加原 PHYS 可计算的“四模块/总读出全零”标志；
- X 加原 CaloNu 读出；
- 若预算允许，在完整有效支持上增加“条件置换电荷”控制，同时独立报告完整支持和全事件支持，不能靠删除缺失事件得到全样本收益。

零标志只用当前读出计算，不假定所有全零都已逐例认证为空 HITS。其语义可在 stage39/40 已配对支持上核对。条件置换应保留组件/来源及 μ 运动学；真 z 条件版本仅作隔离位置混杂的 oracle 诊断，不参与部署。

若零标志模型接近原读出模型，说明部分预测力可能来自二元可观测性/位置信息，必须再测物理响应下的保留程度；**不能据此宣布所有增益都是伪影**。真实“没有沉积”是物理状态，问题是旧模拟把它暴露为确定、无噪声的零，而真实探测器只能给带噪声的证据。[L1]

### 3.2 关键实验：理想 CaloNu 信号与深度的四格诊断

在同一 CaloNu 几何的代表性开发样本上，从已有 HITS 提取四模块的敏感层保存能量或名义无噪声电荷 S，比较：

| 对照 | 输入 | 用途 |
|---|---|---|
| I0 | X | 有限样本基线 |
| Iz | X + 真 z | 测该几何中位置知识的增益 |
| Is | X + S | 测理想敏感层读出的增益 |
| Isz | X + S + 真 z | 判断信号是否在已知位置后仍有能量分配信息 |

truth/HITS 严格进入隔离 oracle；推理输入仍只允许 reco。所有模型在同样的子样本、来源折和预算上重训，不能拿全 fit 基线对小子集增强模型作公平性结论。

**这是理想化参考，不是数学上已证明的探测器信息上界。** 四模块积分不包含全部时间形状，名义卷积也还不是完整历史 digitization。有限容量、样本和优化可能掩盖真实增益；无显著差异要区分“排除具有实用价值的增益”和“统计不足”。

报告 ν log-RMSE、bias、R68、尾部及已保留的灵活 scalar 谱表示；按 reco pμ、真 Eν、y、z、组件和匹配证据分层。CaloNu schema 缺严格 barcode 确认时沿用独立命名的代理，不冒充 confirmed。

建议从已认证的 stage39/40 常规支持开始做描述性信号/transfer/z 图，**不把约百例、少数来源的富集控制直接拿来证明模型提升**。需要学习比较时，再按组件、reco pμ 和来源设计一个有上限的小扩展，例如 2,000–4,000 个开发事件、至少 12 个来源组；这是建议预算，实际可用性未测量。仅取现有 HITS 和必要摘要，不新跑 G4，不要求完整 RDO→PHYS。

用来源组 cross-fitting、单一容量和预设有限 fits，先回答有无可利用信息，再决定是否值得扩大。高 y 若需额外抽样，仅作为独立诊断或用已知包含概率恢复原目标风险，不把富集比例当真实总体。

### 3.3 有理想信号增益后，再测“有噪声还剩多少”

用相同信号 S，建立**独立命名的响应模拟分支**，对所有事件统一采用 s(t)+n(t)，包括 S=0 的事件。历史白噪声只能是一个有明确假设的起点；下一步用经审计的离峰 data 噪声与外部时间标定检验。

这是模型压力测试，不是把随机数填进旧缺失观测。旧 ADC、缺失 mask 和原生观测保持原样；合成响应、原生响应与最终 data 三种结论分别报告。噪声副本是同一物理事例的技术重复，必须留在同一来源折内，也不能当成更多独立事例。

在同一合成样本中比较基线、旧式正半波/零机制、固定模板、有界时间或一个有依据的时间边缘化表示。先只固定一个名义响应和一个预定义压力变化，避免重新开始电子学扫描。

### 3.4 实验结果如何决定投资

| 结果 | 更合理的后续投入 |
|---|---|
| Is 相对 I0、Isz 相对 Iz 都有实用收益；合理噪声后仍保留 | 有预算完成 CaloNu Athena 修复、响应/data 校准与有限能量模型 |
| 理想信号有收益，当前噪声后大幅消失 | 研究可实现的噪声/外部时间/增益改进；把噪声曲线映射到 ν 收益后再定投入，不靠减噪 toy 宣称硬件改善 |
| Is 有益，但已知 z 后的条件增益很小 | 优先恢复几何区域/深度概率；不能只看相关性把 CaloNu 称强子能量计 |
| 理想信号在大多数支持无可测实用增益，只在少数区域有效 | 做可观测性分区和联合谱分析；保留该区域价值，把主要精力转向其他非 μ 活动 |
| 旧零标志贡献明显，物理噪声响应收益大降 | 将原 3.34% 解释限定为旧 MC 条件增益，建立抗这种捷径的训练/评价，不扩大旧结果的物理主张 |
| 区间过宽 | 指出缺少的组件、来源组或高 y 支持；优先补这些样本，不再追加架构扫描 |

上述贡献不能机械相减后解释成唯一因果百分比；各输入冗余、训练非线性和几何混合均影响比较。

## 4. 值得发展的新方法：弱信号不应被迫给出精确时间

stage40 的 94 个弱信号中，43 个时间触边；高信号无此问题。这与振幅接近零时到达时间不可辨识相容，不一定是程序错误。每事例 profile 选一个时间容易把噪声当可移动脉冲；继续微调网格通常不解决这一点。

若第3节支持继续开发，候选方案是**带外部约束的波形似然**：

\[
w_j=A_jg_j(\tau)+B_j+\epsilon_j,\quad \epsilon\sim\mathcal N(0,C),
\qquad L(A)\propto\int L(w\mid A,B,\tau,C)\,p(\tau\mid\text{外部时间标定})\,p(B)\,dB\,d\tau.
\]

其中 C 来自离峰噪声或专门控制，允许时间采样/通道相关；是否 Gaussian、平稳必须验证。外部时序来自可在 data 定义的时钟或 Timing 信号并完成飞行时间关系标定，不能用 HITS 时间。对于晚 shower，公共时间加单脉冲未必足够，应记录模型残差而非无限增加自由度。

输出可以是电荷估计、误差和似然摘要；不强迫弱信号拥有物理时间值，不裁负值。时间先验、基线模型和噪声估计仍可能带来偏差，必须做独立注入/覆盖检查。边缘化不保证优于所有固定模板；它是一个针对 stage40 已知折中的候选。

ATLAS 的 optimal filtering 同时处理振幅、pedestal 和时序，并按信号/噪声条件限制时间修正，提供直接方法参考；其探测器和阈值不能照搬。[L2,L3] 已有一阶时间导数控制没有修正二阶损失，不能再把相同方法包装成新解法。

## 5. 如果 CaloNu 主要受几何限制，怎样继续原目标

### 5.1 利用几何关系，而非重复全局点云网络

保留 F6，新增一组**相对 leading μ 的活动形状**：将其轨迹传播到各 station，在固定物理尺度的管道内/外统计 SpacePoints 或已审计 clusters，计算沿程的活动增长、偏心、非 μ 区占有率和相邻 station 的相对位置变化。跨 station 的局部关系比全局均值/方差更接近 shower 可观测性。

先用小型 BDT 消融，确认计算出的关系变量有效，再决定图网络或 attention 是否必要。不得用未对齐 `Track_hitSet` 建图；“管道外”也不等于真强子，μ 散射、噪声、次级 μ 和 pile-up 要保留。几何半径/匹配门槛按分辨率与 detector 尺度预先确定，不围绕 ν 标签扫描。

stage18/19 只否定了所测空间矩/mean-pooled Deep Sets 的明确实用收益，没有测尽这类关系。这个方向是有物理理由的新增表示，收益未测量。

### 5.2 用深度和可观测性作隐变量，不把真 z 输入部署

stage30 已支持 z 信息，而 stage35 显示位置改变读出效用。可以先只学习“上游/内部/下游等区域”的软概率，再建立区域条件的 transfer 响应或小型专家混合；不要求逐毫米精确顶点。

最终模型可写成对区域求和的 p(Eν|X)，推理仅由 reco 产生区域概率。区域分类准确度本身不是成功标准，必须优于同输入、同预算的 F6 能量模型，并评估地区混合/模拟变化。若实际读出不能识别区域，不用 truth gate 造成虚假改善。

SND@LHC 的工作特别相关：先识别 shower 起点，再联合 target 与下游 HCAL 信号，且用理想敏感层损失作 MC 参考。[L4] 本项目不能照搬其分辨率，因为几何采样与读出不同。

### 5.3 分开 μ 约束与 transfer 分布，允许事例有不同不确定性

在低 μ 动量区，μ 部分已较准。更自然的学习对象是 transfer energy 或 leptonic y 的条件分布，并保留与区域/活动的相关性，再组成 Eν。定义仍为 E_transfer=Eν−Eμ,vertex，它不是已测可见强子能量，也不是完整包含靶静止质量的量热账本。

truth 可作辅助标签，推理不能输入真实 μ 动量或 y。不对所有事件硬施加 Eν≥p_leading：未确认 leading 可能不是 primary。可先在原样本上用一个小型联合输出作受控实验，配以误识别分量，不能靠真值删除事件获得好结果。

这一路径借鉴了中微子重建中“用可见量推断未观测运动学”的原则。[L5] 先验证新增信息，再考虑分位数或轻量混合密度；stage30 未显示扩大完整 q 有明确收益，所以暂不直接上 flow/Transformer。

### 5.4 从“每个事件都很准”转为“全部事件都有合适的响应”

如果某些低 pμ、高 y、下游发生的事件没有足够可见 shower，单事例 Eν 可能确实宽。可以给它宽概率响应，同时利用可观测 shower 的事件提供精细约束；两类都进入联合能谱拟合，不删除困难事件。

部署分类只能由 reco 定义，保留分类迁移、效率、背景和系统误差。研究成果可包括：主样本可靠的能量改善、具有明确适用范围的 shower 信息、可观测性分层后的谱收益。不能承诺所有事件统一达到某个分辨率。

## 6. 对当前评价和路线管理的修正

- **F5/F6、C0/C1 已有独立评价，要保留成果。** stage34 test 与 SIBYLL challenge、stage35 test 均已解封。根据其结果研发的新方法不能再用同一 test 冒充首次确认；来源隔离波形控制也不自动是独立 ν 能量 test。
- **不把每项电荷 gate 都变成永久前置条件。** 必须消除会直接伪造物理结论的错误，但完整历史生产修复应由信息诊断决定规模；不能形成“再加一个控制后才允许问 ν 收益”的无限链。
- **5% 是既定扩展决策门槛，不是物理发现阈值。** 不追认 stage35 达到该门槛，也不因此抹去其 3.34% 条件增益。对新信息诊断另在运行前确定预算和实用阈值；少数物理区域的有效收益可另报告，但保留占比、区间和系统风险。
- **proper score、RMSE 与谱目标分别报告。** 单事例风险、概率质量、统计谱信息和含系统的最终误差不互相替代。stage30 的灵活 scalar 表示可以作为谱基线，暂不再为完整 q 启动扩容。
- **统计预算转向独立物理支持。** 不再围绕同一经验总体增加 bootstrap 层数。保持 unit weights 的研究范围，不反复索要缺失归一化；同时不能将 unit-MC 增益称为实际 flux 平均收益。
- **data 优先检查可测量响应。** 在已审计的独立 μ/离峰控制中测噪声相关、时序、相对增益和位置依赖；MIP 校准不能替代强子标定。MC/data 通道尺度不同，应先建立各自响应和同一无量纲信号意义，而非直接乘 25。
- **模型稳健性要对应物理扰动。** 对 gain/noise/time、材料/shower 和相互作用分别定义变体。SIBYLL/EPOS 只覆盖 flux/母粒子产生挑战。必要时用 nuisance-hardened 或推断目标训练保留对谱有用且对已知扰动不敏感的方向，先有扰动再优化，不能盲目去掉深度或能量相关。[L6,L7]

## 7. 更新后的推进顺序

| 阶段 | 输入和任务 | 必须形成的决策 |
|---|---|---|
| stage42：CaloNu 信息诊断 | stage35 开发分区、F6、既有 HITS；零标记对照、理想信号/z 四格，必要时一次明确标记的噪声响应压力测试 | 主要限制是几何采样、噪声还是旧模拟标记？哪条分支值得扩大？ |
| stage43：只投入一条有证据的方向 | 若信号有用则有限 Athena/响应模型；若深度主导则软区域/局部活动；若采样不足则其他 detector 关系表示 | 新读出/表示在用户重点范围的 ν 风险和谱收益，有无实际改善？ |
| 后续确认 | 新候选冻结；明确新的来源/生产谱系与保留样本，再做 data 响应和物理变体 | 哪一改进能部署、适用区域是什么、系统误差后是否仍值得采用？ |

## 8. 文献与适用边界

- **[L1] Geirhos 等，Shortcut Learning in Deep Neural Networks**，2020，[arXiv:2004.07780](https://arxiv.org/abs/2004.07780)。用可迁移性和受控环境变化辨别捷径。这里将“精确零读出标记”列为待测试捷径，是结合仓库结果的假设，不是论文已证明本项目有问题。
- **[L2] ATLAS，Operation and performance of the ATLAS Tile Calorimeter in Run 1**，2018，[arXiv:1806.02129](https://arxiv.org/abs/1806.02129)，[公开全文信号重建部分](https://arxiv.org/html/1806.02129v2)。振幅/pedestal/时间的 optimal filtering 和弱信号下限制时序自由度；不能照搬 TileCal 阈值或精度。
- **[L3] Sotto-Maior Peralva、de Seixas，The TileCal Energy Reconstruction for LHC Run2 and Future Perspectives**，2015，[arXiv:1510.01690](https://arxiv.org/abs/1510.01690)。独立 pedestal 与噪声协方差进入滤波权重，支持从离峰控制估计 C；本项目仍要验证相关噪声和脉冲形状。
- **[L4] SND@LHC，Studies of Hadronic Showers in SND@LHC**，2025，[arXiv:2504.01716v2](https://arxiv.org/abs/2504.01716v2)，[公开全文](https://arxiv.org/html/2504.01716v2)。shower 起点影响 target/HCAL 能量共享；第4.3节用敏感层能损作理想 MC 参考。是本次“先问采样信息、再问电子学”的直接启发，不能将其强子分辨率搬到 CaloNu。
- **[L5] Kopp 等，Improving Neutrino Energy Reconstruction with Machine Learning**，2024/2025，[arXiv:2405.15867](https://arxiv.org/abs/2405.15867)。不可见运动学和生成器迁移的任务设计可参考；LArTPC 末态可观测性比本项目完整，其收益不是本项目预测。
- **[L6] Alsing、Wandelt，Nuisance hardened data compression for fast likelihood-free inference**，2019，[arXiv:1903.01473](https://arxiv.org/abs/1903.01473)。在已定义模型和 nuisance 方向下，局部压缩可减少 nuisance 敏感性；不是自动修复未知 domain shift。
- **[L7] Wunsch 等，Optimal statistical inference in the presence of systematic uncertainties using neural network optimization based on binned Poisson likelihoods with nuisance parameters**，2020/2021，[arXiv:2003.07186](https://arxiv.org/abs/2003.07186)。用推断误差作训练目标的后续方向，须先建立可用的物理响应变体。
- **[L8] Beck 等，Efficient identification of informative features in simulation-based inference**，2022，[arXiv:2210.11915](https://arxiv.org/abs/2210.11915)。以可边缘化 likelihood 评估观测的后验贡献，提供长期方法参考；当前小预算先用受控消融更直接，不因此引入整套 SBI 基建。

文献事实与本项目方案已区分。本轮没有证明新的最佳架构、没有测出理想 CaloNu 参考增益、没有分解旧零标记的份额，也没有完成新的 data 闭合。
