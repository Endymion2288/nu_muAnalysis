# 下一轮执行 Prompt：stage42 信息诊断

请先读 AGENTS.md、workbook stage30–41、docs/nu_mu_energy_ml_information_budget_plan.md 及总路线第23节。
本轮在具备 CERN 环境的终端执行 stage42，主要回答：CaloNu 的限制来自几何采样、电子学噪声，还是旧模拟专有的精确零标记？
不要默认先完成整套历史 Athena 生产复现；将它保留为信息诊断支持后的条件任务。

保持用户重点 **μ reco p=100–1000 GeV** 及100–250/250–1000子层；不要误把ν能量截在1TeV。
保留F6全部输入、同几何原选择、最高pz leading、truth fiducial及unit权重，不删困难/缺失/尾部事件。
复用stage35开发分区、现有PHYS/HITS和已认证原生reader，先smoke再Condor，不新跑全量G4/PHYS或SHA验证。

先写有上限的协议：事件/来源/fit数、主比较、实用增益、分层和停止条件。
旧stage34/35 test均已评价，本轮开发不能冒充新独立确认；不读取旧test来定方案。
新的真正确认集要有明确来源/生成谱系和冻结协议，波形来源隔离不自动等于新的ν能量test。

A．先做最便宜的零标记对照。
同事件、同F6、同训练/早停/校准和容量，比较基线、加原读出全零标记、加原CaloNu。
标记只由PHYS读出计算；在已联接支持核对其语义，不能假定全部全零都认证为空HITS。
报告ν能量风险、bias/R68/尾和灵活scalar谱表示，按pμ、Eν、y、z、组件/匹配证据分层。
若零标记有收益，也只能说有二元可观测性信息，不能直接说全部CaloNu增益伪造。

B．做理想信号/深度四格诊断。
在代表性CaloNu开发事件上读取已有HITS四模块敏感层保存能量或名义无噪声电荷S，
比较X=F6、X+真z、X+S、X+S+真z；所有模型在相同子样本、来源折和预算上训练。
真值严格隔离oracle，不输入部署。敏感层能量含生产响应修正，不能叫完整强子能量。
已有stage39/40小控制先用于描述；若需学习，冻结一个有预算扩展，例如2000–4000开发事件、至少12来源组，
实际不足就报告缺口。富集高y只作诊断或用正确包含权重，不改变总体风险含义。
采用按来源组cross-fitting、固定小BDT，禁止架构/容量扫描。
四模块积分是理想化参考，不是严格信息上界；区间宽时写证据不足，不用不显著证明无信息。

C．只有B支持理想信号有实用价值时，才测一次统一含噪响应模拟。
所有事件，包括S=0，都走同一明确的s(t)+n(t)模型；固定一个名义与一个预设压力变化。
单独命名合成响应，不把随机噪声填入旧缺失观测后冒充原生数据，旧ADC/mask保持原样。
同事件噪声副本同折，不增加独立事件数。先判断ν信息能保留多少，再决定生产修复规模。
不把电荷RMSE下降折算为ν精度，不根据truth选择时间或逐例最优方法。

按结果只选一条后续主线：
理想和含噪都有收益→有预算的Athena修复/data响应；
理想有、噪声后消失→外部时间约束/噪声协方差/波形似然；
位置主导→软深度区域与相对μ的station局部活动；
采样主要受限→其他非μ信息和不同可观测性事件的联合谱响应。
不要回到TeV动量修复、完整概率网络扩容或反复覆盖率调校。
